## 工作内容

1. 复用 Q1 已记录的远端关系，按受影响范围核验并填写 `module | authoritative_remote | branch | baseline_sha | dev_path | build_path | deploy_path | owner | verified_at | notes`；覆盖 stack、studio/copilot、app-stack/prs-stack 与 infra。
2. 将基准 SHA 固定到可复查的远端 ref；在临时 clone/fetch 后验证对象存在且可从该 ref 到达，不能把本地 `git cat-file` 成功当作远端可克隆证明。
3. PRS 旧 stack 的 5 个未提交文件与已定主线逐文件比对，写 `assets/stack-dirty-files-20260928.md`。记录保留/迁移/已覆盖建议；本 Task 不在任一 stack 工作副本提交或丢弃修改。开发副本在制品清单按读取时状态登记，不把历史“10 个”当作永久数量。
4. s10-stack main 的独有提交以 patch/内容及依赖关系核对是否吸收；标题相似仅供导航，不能据此认定等价。归档、remote/upstream 变更另按实施交接要求办理。
5. 记录 copilot 未提交修改的归属与处理结论，供 F1/T03 冻结合并基准使用。PRS 已接收资料复用 F0/T05，未推送内容不得写成可远端检出的基准。
