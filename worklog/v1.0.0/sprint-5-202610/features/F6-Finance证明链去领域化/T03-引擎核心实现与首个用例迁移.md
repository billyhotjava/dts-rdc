## 目标
实现 ProofEngine 核心，并把 `FinanceSummaryDualReconciliation*`（Service + Registry + cases JSON）作为第一个用例端到端迁移，证明新旧实现的结果一致。

## 技术设计
- **实现**：`ProofEngineImpl`（按 suite 解析 → 并发取数，线程池上限可配置 → 比对 → 写入 run 和 case 结果 → 调用 publisher）、`SqlProofSource`、`TolerancePropCheck`/`DualPathCheck`、`JdbcRunRepository`；
  Liquibase `v1_1_0_010__proof_engine.xml`（run 与 case_result 两张表）。
- **迁移**：把 `finance-summary-dual-reconciliation-cases.v1.json` 转写为 `prs-stack/pack/quality/proof/finance-summary-dual.yaml`；
  新增 REST：`POST /api/ai/proof/suites/{suite}/runs`（手动触发，STUDIO_ADMIN）、`GET /api/ai/proof/runs/{id}`。
- **并行运行比对**：新旧实现在同一数据快照上各跑一次，逐个 case 比对 status 和 diff；此期间旧类保留不动。

## 验证（RED→GREEN）
