## 技术设计
- Spring Boot 4.1.x、JDK 25；模块按领域分包：`space`、`page`、`version`、`attachment`、`sync`、`search`、`comment`、`identity`、`common`
  （Spring Modulith 2.1.x 校验模块边界，与 prs R-002 一致）。
- 持久化：Spring Data JDBC（或 JPA，二选一，推荐 JDBC：模型简单、SQL 可控、适合版本表大字段）；PG 18；HikariCP。
- 错误信封：`{code, message, detail?}`，HTTP 状态与语义一致；业务码如 `PAGE_VERSION_CONFLICT`、`SPACE_FORBIDDEN`。
- OpenAPI：springdoc 生成 `/v3/api-docs`，前端据此生成 TS 类型（T07）。
- 观测：Actuator（liveness/readiness 分离）、Micrometer、JSON 日志（traceId、user、space）。
- 配置全部外部化（环境变量），无状态，支持多副本（同步任务用 PG advisory lock 保证单实例执行，见 F4）。
