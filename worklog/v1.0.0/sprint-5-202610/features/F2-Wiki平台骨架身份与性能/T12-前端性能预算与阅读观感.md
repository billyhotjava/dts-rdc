**优先级**: P0 · **状态**: DONE（2026-09-27：06 §2.3 命令全过，首屏 286 KB，证据 `it/wiki/W5a-perf.md`；已知偏差：RSS 416 vs 400，AppCDS 后续在 W9 评估；观感截图随 W4 用户验收一并确认） · **依赖**: T05–T07（骨架已在 .50 运行，镜像 `w6a3`）

## 目标
阅读页首屏 JS ≤ 300 KB gz、CSS ≤ 60 KB gz，静态资源 gzip + 一年 immutable 缓存，应用常驻内存 < 400 MB；阅读排版与现网 wiki 观感一致，不再暴露内部枚举。

## 技术设计（契约见 design，不在此重复）
| 项 | 契约 / 落点 | 设计出处 |
|----|-------------|----------|
| B7 压缩与缓存 | `application-prod.yml` `server.compression.*`；`/assets/**` → `Cache-Control: public, max-age=31536000, immutable`；`index.html` → `no-cache` | `design/10` §3.7、`design/06` §2.3 |
| B3 启动接口 | `GET /api/wiki/bootstrap` → `{account, spaces, canCreateSpace}`，前端启动只调这一个 | `design/10` §3.3 |
| F5 拆包 | `React.lazy` 路由拆分；`manualChunks`：`vendor-react`、`vendor-antd`、`editor`；Milkdown/CodeMirror/mermaid/KaTeX/Shiki 按需 `import()` | `design/10` §4.5 |
| F5 预算门禁 | `scripts/check-bundle-size.mjs` 读 `dist/.vite/manifest.json`，超预算构建失败（接入 T08 CI） | `design/10` §4.5 |
| F5 数据 | 树节点悬停 150 ms 预取；`staleTime: 30s`；`keepPreviousData` | `design/10` §4.5 |
| F6 观感 | 浅色头部、正文 16px/1.75、最大宽 880px、h2 分隔线；`kind`/`syncStatus` 不以文字枚举显示；空目录页显示子页面卡片；危险操作收进 `⋯` | `design/10` §4.6、`design/05` §8 |
| C7 JVM | SerialGC、小堆、容器上限 768 MB | `design/06` §2.1 |
