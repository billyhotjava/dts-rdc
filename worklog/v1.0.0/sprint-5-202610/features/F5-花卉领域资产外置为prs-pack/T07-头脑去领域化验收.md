# T07: 头脑去领域化验收

**优先级**: P0
**状态**: DRAFT
**依赖**: T02–T06、F4/T05、F4/T06

## 目标
关闭 classpath 回退，删除引擎中的领域资源，证明头脑中已经**没有花卉硬编码**，并且问数行为不变。

## 技术设计
- **步骤**：
  1. `dts.studio.pack.fallback-classpath=false`；
  2. 删除 `engine-ai/src/main/resources/{semantic-packs,governance,prompts,planner}`（F6 仍需要的 finance 配置：如果 F6 还没完成，这些配置在 Pack 中已经存在，引擎代码通过 Resolver 读取，因此仍然可以删除）；
  3. 静态扫描脚本 `engine/tools/domain-leak-scan.sh`，规则如下：
     - 禁用词：`xycyl_`、`flowerbiz`、`rs-flowers`、`adminapi`、`报花`、`加摆`、`撤摆`、`绿植`、`租摆`；
     - 扫描范围：`engine-ai/src/main/**`、`webapp/src/**`（不含 `*.test.*`）；
     - 白名单文件 `engine/tools/domain-leak-allowlist.txt`（例如与 F6 暂未去领域化的 Finance* 相关的条目，必须注明到期 task）；
     - 纳入 CI，发现新增泄漏即失败；
  4. 清空数据库，只安装 prs-pack，再跑 golden set。
- **产出**：`it/IT-05-no-domain-in-engine.md`：扫描输出、白名单清单（每条都有到期 task）、golden set 比对摘要。
