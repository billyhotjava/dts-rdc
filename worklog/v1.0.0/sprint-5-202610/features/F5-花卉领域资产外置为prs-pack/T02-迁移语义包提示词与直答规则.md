# T02: 迁移语义包、提示词与直答规则

**优先级**: P0
**状态**: DRAFT
**依赖**: T01

## 目标
把 6 个语义包（账本#12）、`prompts/*`、`planner/business-direct-responses.json`（账本#13）迁到 prs-pack，保持内容不变，并登记到 manifest。

## 技术设计
- **映射**：

  | 源（engine-ai/src/main/resources/…） | 目标（prs-stack/pack/…） | manifest capability |
  |---|---|---|
  | `semantic-packs/flowerbiz.json` 等 6 个 | `ontology/<domain>.json` | `ontology` |
  | `prompts/flowerbiz-constraints.txt` | `prompts/flowerbiz/constraints.txt` | `prompts`（kind=constraints, domain=flowerbiz） |
  | `prompts/flowerbiz-few-shots.txt` | `prompts/flowerbiz/few-shots.txt` | `prompts`（kind=few-shots） |
  | `prompts/settlement-*` | `prompts/settlement/*` | `prompts` |
  | `planner/business-direct-responses.json` | `persona/direct-responses.json` | `persona`（kind=direct-responses） |

- **迁移方式**：使用 `git mv` 无法跨仓库，因此在 prs-stack 中新增文件，提交信息注明来源 `dts-studio@<sha>:engine/engine-ai/src/main/resources/...`，保证可以追溯；
- **语义包中的 metrics**：按 ADR-007 增加 `indicatorRef` 字段（能对应上 stack 指标的填写，对应不上的留空，并在 F8/T01 的对照表中登记），`expr` 保留；
- **引擎侧**：源文件先**不删除**（fallback 仍然需要），由 T07 统一删除。
- **ontology schema 的校验差异**：如果 F4/T01 的 schema 对某个现有包报错（例如某个包缺少 `signals`），修正 schema 的必填规则，而不是修改业务内容（除非确实是数据错误，需记录）。
