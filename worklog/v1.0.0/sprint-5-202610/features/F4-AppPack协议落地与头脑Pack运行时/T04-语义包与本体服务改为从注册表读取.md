# T04: 语义包与本体服务改为从注册表读取

**优先级**: P0
**状态**: DRAFT
**依赖**: T03

## 目标
`SemanticPackService`（账本#12，`:21` 从 classpath 读取）改为通过 `PackAssetResolver` 获取 `ontology` 资产；
`OntologyService`、`BusinessObjectCatalogService`、`IntentRouterService` 等下游**零改动或只做最小改动**。

## 技术设计
- **改造点**：
  1. 抽出接口 `SemanticPackSource { List<SemanticPack> loadAll(); long generation(); }`，提供两个实现：
     - `RegistrySemanticPackSource`（默认）：读取所有 ACTIVE pack 中 kind=`ontology` 的资产，反序列化为现有的 `SemanticPackService.SemanticPack` record；
     - `ClasspathSemanticPackSource`（回退）：保留原有逻辑，仅在 `dts.studio.pack.fallback-classpath=true` 时启用（过渡期默认 true，F5/T07 验收后改为 false，F13 之后删除）。
  2. `SemanticPackService` 的缓存：以 `generation` 作为版本号，generation 变化时重建索引（不重启进程）；
  3. **多 pack 同 domain 冲突**：两个 ACTIVE pack 声明同一个 `domain` 时，安装阶段就拒绝（T03 的校验中增加跨 pack 检查），运行时不做合并；
  4. 答案溯源：`CopilotChatContract` 的 `sourceRefs[]` 增加 `{type:"pack", name, version}`（与 F12 的 UI 契约保持一致）。
- **不改动**：`OntologyService.OntologyModel` 的内部结构。
