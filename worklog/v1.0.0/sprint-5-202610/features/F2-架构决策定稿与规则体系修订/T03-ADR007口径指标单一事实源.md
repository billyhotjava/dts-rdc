# T03: ADR-007 口径/指标单一事实源

**优先级**: P0
**状态**: DRAFT
**依赖**: 无

## 目标
定稿"口径（caliber）和指标（indicator）的唯一事实源是 stack governance"，并明确头脑侧 `caliber-rules.v1.json`、语义包里的 `metrics` 和 stack `Indicator*` 三者的主从关系。

## 技术设计
- **事实输入**：账本#13（`caliber-rules.v1.json` + `CaliberRuleRegistry`）、账本#12（语义包 `metrics[]`，含 `expr`、`caliber`）、账本#25（stack `governance/Indicator*`，有定义/派生/发布/证据）、账本#19（S29 联邦配置已存在）。
- **决策要点**：
  1. 指标定义（名称、表达式、口径说明、维度、发布状态）**只在 stack 编辑**；
  2. 语义包中的 `metrics[]` 改为**引用**：`{"indicatorRef":"stack://indicator/<code>@<version>"}`，同时保留 `expr` 作为离线缓存与降级用途，并由 CI 校验两者一致；
  3. `caliber-rules`（SQL 级防护规则，例如"金额必须用 xx 列"）属于**查询护栏**，不是指标定义：归 AppPack 的 `quality_rules`/`guardrails`，由头脑执行；与 stack 指标冲突时以 stack 为准；
  4. 降级：stack 不可用时，头脑使用最近一次同步的缓存，并把 `accuracyEvidence` 降一级、给出原因 `CALIBER_CACHE_STALE`。
- **产出**：`docs/adr/ADR-007-caliber-sot.md`，附"语义包 metrics → stack indicator"字段映射表。
