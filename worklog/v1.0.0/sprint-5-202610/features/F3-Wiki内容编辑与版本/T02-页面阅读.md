## 技术设计
- 渲染：前端 `markdown-it` + 插件（表格、任务列表、代码高亮 Shiki、Mermaid、脚注、KaTeX 可选）；与现网 VitePress 渲染效果保持一致的部分：`breaks: true`、README 目录页。
- 相对链接解析：页面内 `./xxx.md`、`../a/b.md` 按 git 路径解析到目标页面 id（后端提供 `GET /api/wiki/spaces/{slug}/resolve?path=`），实现"研发文档里的相对链接在 wiki 中可点"。
- 图片：`./assets/x.png` 解析为附件 URL（T08）。
- XSS：Markdown 渲染禁用原始 HTML 或用 DOMPurify 白名单（内部工具也要做，防止粘贴恶意内容）。
- 目录（右侧 outline）、锚点、代码复制按钮。
