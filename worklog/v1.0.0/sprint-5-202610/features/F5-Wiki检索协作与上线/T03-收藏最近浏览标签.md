## 数据设计

以 design/02 §6 为准，收藏/浏览采用新的自定义 Liquibase changeset + JdbcTemplate，不作为 JHipster 实体，不生成无空间权限的 CRUD。

- `page_favorite(user_id, page_id, created_at)`，联合主键/唯一约束 `(user_id,page_id)`；`user_id` 外键及类型复用 `jhi_user.id`，禁止另建 app_user。
- `page_view(user_id, page_id, viewed_at)`，同一用户/页面一条，按服务端时间 upsert；每用户保留最新 50 条，时间相同按 page_id 稳定排序。锁定用户对应行后，在同一短事务内 upsert 与裁剪，验证并发下仍不超过 50 条。
- 用户/页面物理删除时清理关联；软删除/撤权即时在读取 SQL 中过滤，过滤发生在排序、分页和 total 之前，不能返回不可见标题/数量。
- 标签以完整 Markdown frontmatter 的 `tags` 为事实源，`page_meta.tags` 为派生检索字段；既有 Label/page_label 仅可作可重建投影，不再独立写一套 PG 标签。修改标签使用属性编辑/正文保存流程，带 baseVersionNo 并生成版本；GIT 页正常写回 git。

## API 与交互

路径均在 `/api/wiki` 下，主体来自服务端登录上下文，不接受查询参数中的 userId。

| 方法/路径 | 行为 |
|---|---|
| `GET /me/favorites?page=&size=` | 本人当前可见收藏；page 从 0 开始，默认 20、上限 50，响应 `{items,page,size,total}` |
| `PUT /me/favorites/{pageId}` | 校验页面可读后幂等收藏，204 |
| `DELETE /me/favorites/{pageId}` | 只删自己的记录，幂等 204，不泄露他人收藏或页面是否存在 |
| `POST /pages/{pageId}/view` | 页面成功展示后登记本人浏览，校验当前可读，204；预取/爬虫不记浏览 |
| `GET /me/recent-pages` | 最新 50 条内的可见项，响应 `{items}`；不暴露被过滤数量 |

标签在既有属性面板编辑，搜索/筛选消费 page_meta；界面不同时显示两套可编辑标签。收藏按钮与最近浏览具备空/加载/错误状态；无权限页面按现有读取策略返回 404。
