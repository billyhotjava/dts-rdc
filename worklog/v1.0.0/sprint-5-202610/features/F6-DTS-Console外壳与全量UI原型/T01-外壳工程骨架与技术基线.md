# T01: 外壳工程骨架与技术基线

**原编号**: 新增（2026-09-27，ADR-013 交付方法：模板化 UI 原型先行）

**优先级**: P0 · **状态**: READY · **依赖**: F0/T19

## 目标
`dts-studio/console/` 可构建、可本地运行的 antd 6 外壳：登录占位、布局、路由、主题、模块联邦 host，CI 通过。

## 技术设计 / UI 规格
- 版本与 PRS BOM（R-012，prs Sprint-1 已确认）对齐：Node 24 LTS、pnpm 11、TypeScript 6.0、Vite 8.2、React 19.2、antd 6.6、React Router 8.3、TanStack Query 5、Tailwind 4（与 stack webapp 一致，只用于布局工具类，不替代 antd 组件）。
- 目录：`src/app/`（壳：布局、路由、守卫）、`src/features/<surface>/`（按页面域组织）、`src/shared/`（组件、hooks、api client）、`contracts/`（OpenAPI）、`mocks/`（MSW）。
- 布局借鉴 shadcn-admin：可折叠侧栏 + 顶栏（全局搜索 ⌘K、租户/角色显示、主题切换、用户菜单）+ 面包屑 + 内容区；移动端侧栏抽屉。
- 模块联邦 host：沿用 PRS 原型 `frontend/src/remote/{exposes,remote-entry}.ts` 的约定挂载 PRS 页面；插件版本按 R-012 在本 Task 选定并记入 `assets/console-bom.md`。
- 运行模式：`VITE_API_MODE=mock|bff`；mock 模式启动 MSW，bff 模式经 dts-gateway 访问 BFF。
- 与旧 webapp 的关系：copilot webapp（F1 合并后位于 studio `engine/webapp`）在 BL-C/T08 切换完成前继续可用，作为回退路径。
