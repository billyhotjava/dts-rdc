# T11: PRS 与 stack 页面挂载

**原编号**: 新增（2026-09-27，ADR-013 交付方法；09-28 按 PRS 原型现状细化）

**优先级**: P1 · **状态**: DRAFT · **依赖**: T01、T02、T04

## 目标与本月范围

用与 T01 锁定 BOM 相同的最小 PRS mock remote（单页）验证宿主/远程模块约定。3 月 `prs-stack/frontend` 仅作为原型参考，不直接挂载或推定与新 React/antd 单例兼容。10 月不接真实 PRS 网络，不在本 Task 重写 PRS 业务页面。

## 设计与产出

- 样例单独放在 Console 的 fixtures/examples 范围；记录 host/remote 版本、挂载/卸载、路由基址、BFF client、主题、加载失败与清理协议。使用实际选定插件验证，不能仅将原型的普通导出文件称为已实现模块联邦。
- 样例消费 T04 的 mock client；身份来自宿主但最终授权由服务端决定，不复制 token 到 URL、remote 配置或浏览器持久化。
- stack BI 本期演示新窗口链接与登录跳转。真实授权深链由 F0/T17、BL-D/T10 明确后交 BL-C/T08；iframe 不在本次默认承诺内。
- mock 原型中的“直达原应用”明确标为模拟导航。真实接入只能使用经配置的原应用地址及原鉴权路径，不回落到已决定不迁移的 copilot webapp。
