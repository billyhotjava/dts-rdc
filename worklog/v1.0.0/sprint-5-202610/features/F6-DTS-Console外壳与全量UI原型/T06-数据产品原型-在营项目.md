# T06: 数据产品原型-在营项目

**原编号**: 新增（2026-09-27，ADR-013 交付方法：模板化 UI 原型先行）

**优先级**: P0 · **状态**: DRAFT · **依赖**: T02–T04

## 目标
`/data/products` 展示数据产品目录；首个“在营项目”详情页包含明细、计数、口径版本、负责人、更新时间、来源和质量结果。

## 技术设计 / UI 规格
- 列表：名称、负责人、口径版本、新鲜度、质量状态、可见范围。
- 详情：摘要头（计数 + 快照时间 + 质量徽标）；明细表（项目 ID、名称、负责人、状态，服务端分页）；口径说明（在营规则、粒度、过滤条件）；来源与血缘摘要；异常横幅（过期、质量失败、未发布、撤回）。
- 缓存与降级表现遵守产品能力规划 §3：缺权限不显示成“无数据”。
- 契约 `data-products.openapi.yaml`；字段映射以 F0/T14、BL-D/T17 为准，原型阶段在契约中标 `x-status: draft`。
