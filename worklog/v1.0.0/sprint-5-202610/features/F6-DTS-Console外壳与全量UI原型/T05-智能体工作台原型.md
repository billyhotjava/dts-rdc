# T05: 智能体工作台原型

**原编号**: 新增（2026-09-27，ADR-013 交付方法：模板化 UI 原型先行）

**优先级**: P0 · **状态**: DRAFT · **依赖**: T02–T04

## 目标
业务用户在 `/workspace` 提问，看到答案卡片（数值、明细入口、证据等级、来源、口径版本、新鲜度、审计号），并能切到人工路径。

## 技术设计 / UI 规格
- 布局：左侧会话列表；中间对话流；右侧上下文面板（当前租户、引用来源、口径说明）。
- 答案卡片：数值 + 明细表入口（跳 `/data/products/:id?snapshot=`）+ 证据等级徽标 + 来源引用 + 审计号（跳 `/audit?traceId=`）。
- 状态：思考中（流式）、拒绝（缺租户/无权限，显示原因）、失败（traceId）、降级（AI 不可用时引导人工路径）。
- 复用 copilot 现有工作台的交互经验（账本#20），组件按 T03 重建；契约 `workspace.openapi.yaml`（会话、消息、流式事件）。
