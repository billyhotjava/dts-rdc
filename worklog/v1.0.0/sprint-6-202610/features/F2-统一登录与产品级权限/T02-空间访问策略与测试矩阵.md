# T02: 空间访问策略与测试矩阵

**优先级**: P0 · **状态**: DRAFT · **依赖**: T01、F1/T02

## 技术设计
- `SpaceAccessPolicy.canRead(user, space)` = admin ∨ 拥有 `space-<slug>`；`canWrite` = canRead ∧ (editor ∨ admin)。
- 所有 Repository 查询**带空间过滤**（列表、搜索、最近更新、评论），不在 Controller 事后过滤，避免遗漏泄露。
- 搜索结果、最近更新、@提及候选同样按可读空间过滤（F7/F8 复用同一策略）。
- 移植现网 17 项权限矩阵（见 `dts-rdc` 提交 `c0b7807` 的测试）为 MockMvc/集成测试。
