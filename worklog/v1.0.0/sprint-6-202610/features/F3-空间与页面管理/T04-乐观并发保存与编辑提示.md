# T04: 乐观并发保存与编辑提示

**优先级**: P0 · **状态**: DRAFT · **依赖**: T02

## 技术设计
- 保存带 `baseVersion`；不一致 → 409，返回当前版本内容；前端提供"查看差异 / 加载最新 / 用我的版本覆盖（需确认）"（沿用现网编辑器交互，账本 #2）。
- 软编辑提示：打开编辑时 `POST /api/pages/{id}/editing`（心跳 30 s，TTL 90 s），其他人打开时看到"张三正在编辑"；不加硬锁。
- 草稿：服务端自动保存草稿表 `page_draft(page_id, user_id, content, updated_at)`（替代现网仅浏览器本地草稿）。
