# T01: 中文全文检索

**优先级**: P0 · **状态**: DRAFT · **依赖**: F0/T03、F2/T02

## 技术设计
- 索引对象：页面标题（权重高）、最新版本正文、附件文件名；只索引最新版本。
- 实现依 F0/T03：pg_bigm → `GIN(content gin_bigm_ops)` + `bigm_similarity` 排序；zhparser → `tsvector` 生成列 + `ts_rank`。
- 查询永远带 `space_id IN (可读空间)`（F2/T02）。
- 高亮摘要：`ts_headline` 或应用层截取命中片段。
- 顶栏全局搜索框：输入即搜（debounce 300 ms），下拉显示前 8 条，回车进结果页。

## 验证
- [ ] F0/T03 查询集召回率不低于 spike 结论；无权空间内容永不出现（测试矩阵）
