# T03: 前端骨架

**优先级**: P0 · **状态**: DRAFT · **依赖**: F0/T01

## 技术设计
- React 19 + TypeScript（strict）+ Vite + antd 5；路由 React Router；数据请求 TanStack Query；类型由 OpenAPI 生成（`openapi-typescript`）。
- 布局（Confluence 式）：
  ```
  ┌ 顶栏：Logo | 空间切换 ▾ | 全局搜索 | 新建 | 通知 | 用户菜单 ┐
  │ ┌ 左栏：空间首页 / 页面树（可折叠、拖拽） ┐ ┌ 正文：面包屑 · 标题 · 元信息 · 内容 · 评论 ┐ │
  └──────────────────────────────────────────────────────────────┘
  ```
- 路由：`/`（我的空间）、`/s/:space`（空间首页）、`/s/:space/pages/:id`、`/s/:space/pages/:id/edit`、`/s/:space/pages/:id/history`、`/search`、`/admin/sync`。
- 视觉：延续现网 wiki 的主色（#2f6f5e），支持暗色；四态（空/加载/错误/成功）组件统一封装。
