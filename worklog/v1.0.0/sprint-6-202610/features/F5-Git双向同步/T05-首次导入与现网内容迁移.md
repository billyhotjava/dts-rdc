# T05: 首次导入与现网内容迁移

**优先级**: P0 · **状态**: DRAFT · **依赖**: T03

## 技术设计
- 首次同步 = 对同步根做全量入站（每个文件 version 1，source=GIT，git_commit=该文件最后一次提交的 sha，作者取该提交作者）。
- 可选"导入历史"：对每个文件回放 `git log --follow` 的历史生成多个版本（开关，默认只导最近 20 个版本，控制体量）。
- 现网内容：
  - dts-rdc 的 `docs/`、`worklog/` → DTS 空间（git 绑定）；
  - 现网 `sandbox/` → 新建"练习区"空间（wiki 原生页，不再进 git）；
  - dts-rdc 中现网临时 PRS 空间 `products/prs/` 的内容：按 Q3 决定迁往 prs-stack 或删除；
  - 现网 .50 上尚未推送到 GitHub 的网页编辑提交（`/data/dts-wiki/repo`）须**先推送或合并进 GitHub**，再做首次导入，避免丢失。
- 校验：页面数 = md 文件数；随机抽 20 页内容 sha 与 git 一致。
