# T06: 冲突检测、三方合并界面与同步监控页

**优先级**: P0 · **状态**: DRAFT · **依赖**: T03、T04

## 技术设计
- 冲突页在页面树、页面顶部显示红色徽标"同步冲突"；编辑者和管理员收到通知（F8）。
- 合并界面：左"wiki 版"、右"git 版"、下方可编辑结果（Monaco/CodeMirror diff 视图），预填自动三方合并（基线 = 上次同步版本）结果，冲突块高亮。
- 合并提交 → `source=MERGE` 版本 → 出站写回 git。
- 同步监控页 `/admin/sync`：每个仓库的最后同步时间、`last_synced_commit`、待推送数、冲突数、最近错误；"立即同步""重试"按钮。
- 告警：连续 10 分钟同步失败 → 状态页红色 + 日志告警（接入 runbook）。

## 验证
- [ ] 构造冲突：网页改第 3 行、git 改第 10 行 → 自动合并成功；两边改同一行 → 进入人工合并，结果正确写回
