# T03: 并行运行、切换与回退

**优先级**: P0 · **状态**: DRAFT · **依赖**: F5/T05、T02

## 技术设计
- 并行期：新 wiki 在 `wiki2.yuzhicloud.com`；现网 wiki 继续可用但**只读**（关闭现网编辑，避免两套系统同时写 git 造成混乱）——并行期约 1 周。
- 切换：
  1. 冻结现网编辑，确认 .50 现网工作仓库的本地提交已全部推送到 GitHub（账本 #9，需 deploy key）；
  2. 新 wiki 执行一次全量同步并校验；
  3. 阿里云 `wiki.yuzhicloud.com` vhost 改指新 wiki；Keycloak `dts-wiki` redirect 加新回调；
  4. 旧地址重定向：`/p/<slug>/docs/...` → 新页面 URL（按 git_path 查页面 id，`GET /r?space=&path=` 重定向端点）；
  5. 现网容器停止（保留 30 天，不删数据）。
- 回退：vhost 指回现网容器并恢复其编辑功能；新 wiki 期间的网页编辑已推送到 git，现网重新拉取即可，不丢数据。
