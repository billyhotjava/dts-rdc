# T03: 附件存储、上传、列表与预览

**优先级**: P0 · **状态**: DRAFT · **依赖**: F1/T02

## 技术设计
- 存储接口 `BlobStore { put(sha256, stream); get(key); }`，v1 实现 `FileBlobStore`（`/data/dts-wiki-v2/attachments/<sha256前2位>/<sha256>`，按内容去重）；后续可换 `S3BlobStore`（SeaweedFS）。
- 附件表记录 filename、mime、size、sha256、所属页面、git_path（git 页的附件同步到仓库；>20 MB 的附件不进 git，仅存 wiki 并在页面标注）。
- 下载 `GET /api/attachments/{id}`：鉴权后以 `Content-Disposition` 输出；图片/PDF 内联预览，Office 提供下载（在线预览为后续项）。
- 页面"附件"标签页：列表、上传、删除（软删除）。

## 验证
- [ ] 同一文件上传两次只存一份；无权空间的附件 404
