# T02: 图片粘贴上传

**优先级**: P0 · **状态**: DRAFT · **依赖**: T01、T03

## 技术设计
- 粘贴/拖拽图片 → `POST /api/pages/{id}/attachments`（multipart）→ 返回 `{id, markdownLink}`；插入 `![名称](./assets/<日期>-<hash>.png)`。
- git 绑定页的图片随页面同步到仓库同目录 `assets/`（与现网规则一致，账本 #2）；wiki 原生页的图片仅存附件存储。
- 限制：PNG/JPG/GIF/WebP，≤ 10 MB；拒绝 SVG（XSS）。
