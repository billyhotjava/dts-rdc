# T12: 列级脱敏与行级策略扩展点

**原编号**: Sprint-5 F10/T06（2026-09-26 按月度 Sprint 整合重编号）

**优先级**: P2
**状态**: DRAFT
**依赖**: T08

## 目标
在 QueryGateway 中预留"结果集后处理"扩展点，支持按角色做列级脱敏（例如客户联系方式、金额），为将来接入 stack 的数据安全策略或 Ranger 做准备（ADR-009 的 v2 路线）。

## 技术设计
- **SPI**：`ResultPolicy { QueryResult apply(QueryContext ctx, DatasourceRef ds, QueryResult r); }`，按顺序链式执行；
- **本期实现**：`ColumnMaskingPolicy`，规则来自 Pack 的 `guardrails`（新增 kind `masking`：`{column_pattern, roles_exempt[], mask: "partial|hash|null"}`）；只按列名或别名匹配（AST 中能解析出来源列时优先使用来源列）；
- **限制说明**：列级脱敏依赖列名匹配，可以被别名绕过 → 必须使用 AST 解析出的来源列；无法确定来源的表达式列（例如 `concat(phone, '')`）→ 对受保护列所在的表，默认拒绝在表达式中使用受保护列（在 SqlGuard 中增加检查）；
- 审计中记录被脱敏的列。
