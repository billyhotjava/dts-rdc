### UI/UX 规格
主竖线走查（即最终验收脚本）：
1. 打开 `https://studio.<domain>/workspace` → 跳转登录 → 专用验收账号（凭据不写文档）；
2. 输入"当前在营项目数" → 流式显示答案；
3. 答案卡片显示：数值、证据等级（HIGH/MEDIUM）、来源 `pack: prs-flower@1.x.x`、指标 `stack v?`、审计号；
4. 点击"保存为卡片" → 在 stack 分析中心打开；
5. 以 bob 登录重复第 2 步 → 结果符合各自可见项目集合，且不能访问异租户项目；计数允许相同；
6. 管理员在能力包页面回滚 Pack → 再次提问，来源版本随之变化。
