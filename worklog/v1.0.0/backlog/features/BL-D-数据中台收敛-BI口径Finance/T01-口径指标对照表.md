## 目标
产出 `assets/caliber-indicator-map.md`：把语义包中的 `metrics[]`（账本#12）、`caliber-rules.v1.json`（账本#13）与 stack 已发布的指标（账本#25）逐个对齐。

## 技术设计
- **数据采集**：
  1. 用 `jq` 提取 6 个语义包的 `metrics[] | {domain, name, object, expr, caliber}`；
  2. 提取 `caliber-rules.v1.json` 中的规则 id、适用 domain、约束内容；
  3. 调用 stack 的 `GET /api/governance/indicators`（使用 S29 已有的服务账号，账本#19），导出已发布的指标列表。
- **表格列**：`pack_metric | domain | pack_expr | stack_code | stack_version | stack_expression | 一致性(一致/表达式不同/stack 缺失/pack 缺失) | 处置 | 负责人`。
- **判断一致性**：先做规范化（去除空白、统一引号和大小写）再比较；语义相同但写法不同的，人工确认后标记为一致；
- **caliber-rules**：逐条标注"查询护栏（留在 Pack guardrails）"或"其实是指标定义（应迁到 stack）"。

## Definition of Done
- [ ] 表格覆盖全部 metrics 与 caliber 规则，负责人确认
