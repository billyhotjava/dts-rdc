# PRS 花卉租赁 · 产品文档

花卉租赁业务系统，是 DTS 平台面向花卉租赁行业的 App（`dts-app-stack/prs-stack`）。

## 目录规划

| 目录 | 内容 |
|------|------|
| `architecture/` | 系统架构、模块边界、与 DTS 平台（stack / studio）的集成 |
| `domain/` | 业务域与统一语言：报花、加摆、撤摆、在营项目、结算…… |
| `integration/` | 身份、数据契约、AppPack、老系统绞杀共存 |
| `deployment/` | 部署与运维 |
