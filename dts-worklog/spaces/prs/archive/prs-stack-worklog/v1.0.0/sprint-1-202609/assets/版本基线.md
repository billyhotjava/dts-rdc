原则：R-012（取**最新的稳定版本**：有 LTS 的取最新 LTS，没有 LTS 的取经过一段时间验证的最新版本线；不用开发版/预览版）。
核实日期：**2026-09-18**。核实来源：endoflife.date API、Maven Central（`maven-metadata.xml` 与 POM 发布时间）、npm registry、
GitHub Releases、openjdk.org、Keycloak 官方升级指南。
用途：F2/T01 ① BOM 章节直接引用；F2/T03-A 以本表为准做兼容性验证。锁定后，Sprint-1 期间版本线不变，只跟进同一版本线内的安全补丁；版本线调整放到下一个 Sprint 的升级窗口，按同一规则复核。

状态：**已确认**（2026-09-18，技术负责人确认）。本表即 Sprint-1 的锁定版本；
仍待关闭的两项不改变锁定结论：F2/T03-A 兼容性验证（不兼容的组件按 R-012 规则另选版本并记修订）、Liquibase FSL 法务结论（不通过则换 Flyway 12.11.0）。
变更流程：只能通过升级窗口或 T03-A 结论修改，每次修改都要升版本号、写修订记录并同步 F2 规范。

## 1. 选版规则（R-012）

1. **不用开发版**：alpha、beta、RC、里程碑（M）、nightly、EA、canary 一律不用。
2. **有 LTS 的组件取最新 LTS**，并用该 LTS 线的最新补丁版本（如 JDK、Node.js）。
   新的 LTS 正式发布后，在下一个升级窗口切换。
3. **没有 LTS 的组件取成熟的最新稳定版本线**：
   - 该次版本线（x.y）首个版本发布满 **30 天**；
   - 所属主版本（x）首个版本发布满 **90 天**；
   - 在选中的版本线内取**最新补丁版本**（补丁含安全修复，不设等待期）。
4. **同一主版本内、升级说明里没有影响本系统的破坏性变化时，直接用最新版本**。
   Keycloak 就按这一条处理：26.3 → 26.7 同属 26 主版本，直接使用 26.7.4（见 §5）。
5. **与 dts-stack 共用实例的组件**（Keycloak、Kafka）：共享实例一并升级到按本规则选出的版本（B-008），
   stack 侧按升级说明做回归；客户端库与实例版本保持一致。
6. **许可证筛查**：GitHub 仓库已归档的项目不选；非 OSI 许可证（FSL、AGPL、SSPL 等）需法务确认后才能使用。
7. **持续跟进**：Renovate 配置 `minimumReleaseAge`（次版本 30 天、主版本 90 天、补丁版本不等待）；每个 Sprint 留升级窗口；主版本升级走 spike。

## 5. Keycloak 26.3.4 → 26.7.4 升级评估（规则 4）

结论：同一主版本内的升级，官方升级说明以安全加固为主。对 prs 新建的 flower / flower-test realm **没有阻碍**，直接用 26.7.4。
共享实例上 dts-stack 的 realm（S10）需按下表做回归，由 stack 运维方执行（F3/T05 跟进，B-008）：

| 版本 | 变化 | 检查点 |
|---|---|---|
| 26.4.3 / 26.6.3 | 重定向 URI 通配符规则收紧（`https://example.com*` 不再允许，改为 `/*`） | 检查所有 client 的 redirect URI |
| 26.5.0 | 用户会话默认持久化，空闲会话宽限期取消 | 核对会话超时配置与 DB 容量 |
| 26.5.4 | Admin API 不再支持部分更新用户 | 检查 dts-admin 等调用 Admin API 的代码 |
| 26.6.0 | hostname 配置项有破坏性变化 | 按新配置项改写启动参数 |
| 26.6.2 | 令牌自省要求调用方 client 在令牌的 `aud` 中 | 检查 forwardAuth 等自省调用方的 audience mapper |
| 26.6.4 | Java keystore 文件必须放在按 realm 划分的目录 | 检查 keystore 挂载路径 |
| 26.7.0 | IdP alias 创建后不可改；组织成员查询默认返回精简信息；X509 需配置 CA Subject DN | prs 查询组织成员时需带 `briefRepresentation=false` |
| 26.7.1 | 经 protocol mapper 授予的管理员角色不再获得 Admin API 权限 | realm 专属管理员组要直接分配角色（F3/T01） |
| 26.7.2 | 客户端发起的旧式账号关联端点默认关闭 | 确认 stack 是否使用 |
| 26.7.3 / 26.7.4 | `kc.` 前缀声明保留；含 `state`/`code` 的重定向 URI 被拒；授权服务资源 URI 规范化 | 检查自定义声明命名与授权策略 |

来源：Keycloak 官方升级指南（keycloak.org/docs/latest/upgrading）。
