## 目标和范围
起草规范 v0.1，共十节，每条标注"锁定/假设/延后"：
① **BOM 与版本**（锁定）：按 R-012 直接引用已确认的 `assets/版本基线.md` v1.0，不在规范里重复写版本号；
  写明选版规则（LTS 优先、成熟度等待期、同主版本直接用最新）、共享组件（Keycloak、Kafka）连同实例升级的规则、许可证筛查结论（Liquibase FSL 法务意见、MinIO 已归档不选）、
  Renovate 与升级窗口机制、新 LTS 发布后的切换节奏（JDK 29、Node 26）；无 SCA/Nacos/Sentinel/Boot Admin；T03-A 不兼容项的处理结论回写本节。
② **服务/模块模板**：Spring Modulith 模块化单体，每个域一个模块，模块间只经事件或公开 API，架构测试强制边界；
  默认能力：验头、租户上下文、审计、幂等、outbox（事件发布表）、MCP；鉴权在边缘，服务只验 `X-DTS-*` 头。
③ **API 规范**：资源/命令式设计，不复刻老 RPC 命名；OpenAPI、envelope、分页、版本、错误码；读能力的 MCP 投影约定。
④ **事件规范**：CloudEvents 信封（扩展属性含 `tenantid`）+ 首批状态变更事件目录。
⑤ **数据规范**：Liquibase；Long 主键（雪花 bigint，JSON 转字符串）；collation、pg_trgm；
  绞杀期同步与 ODS 暴露约定引用 F6；**多租户数据约束**（下一节）。
⑥ **多租户规范（R-010）**：
  - 业务表 `tenant_id bigint NOT NULL`，唯一约束和业务索引以 `tenant_id` 打头；
  - `ENABLE` + `FORCE ROW LEVEL SECURITY`，策略 `USING/WITH CHECK (tenant_id = current_setting('app.tenant_id', true)::bigint)`；
  - 每个事务开始时 `SET LOCAL app.tenant_id`；应用账号不是表的所有者、不带 BYPASSRLS；Liquibase 使用独立的所有者账号；
  - 取不到租户返回 0 行（fail-closed）；平台级表归 `platform` schema；
  - 单号计数表 `(tenant_id, doc_type, period)` 行锁取号；
  - Flowable 使用 `tenantId`；缓存键、对象键、Kafka 消息头、日志与链路属性都带租户；监控指标不以租户作为标签；
  - 规则、模板、字典、流程采用"平台默认 + 租户覆盖"；
  - 定时任务按租户循环执行。
⑦ **安全规范**：密钥（假设，B-006）、脱敏、审计双写、制单审核分离约束；agent 代用户调用采用 token exchange（引用 F3/T05）。
⑧ **前端规范**：React 路由/权限/请求/SSE；H5 容器与 BFF 会话（Sprint-2 实现，本期只定原则）；agent UI 协议引用 copilot（R-009）。
  **TypeScript 规范（R-001 补充）**：
  - 所有源码、构建配置（`vite.config.ts`）、测试用 `.ts`/`.tsx`；`tsconfig` 开启 `strict`、`noUncheckedIndexedAccess`，关闭 `allowJs`；
  - 禁止显式 `any`（lint 报错），确需时用 `unknown` 加类型收窄；`@ts-ignore` 禁用，`@ts-expect-error` 必须写原因；
  - 接口类型从后端 OpenAPI 生成（生成物不手改，接口变更即重新生成）；agent UI 消息块类型从 copilot 发布的契约生成；
    `id` 等 Long 字段在类型中为 `string`（与 API 规范一致）；
  - 外部输入（接口响应、URL 参数、容器 SDK 回调）在边界处做运行时校验，不只依赖编译期类型；
  - CI 必须执行 `tsc --noEmit` 与 typescript-eslint 检查，失败即阻断合并；
  - JS 例外登记表：文件、原因、补充的 `.d.ts`、清理计划；
  - 类型生成、运行时校验、lint 等工具的选型在本节确定，版本按 R-012 选定后以修订方式补入版本基线。
⑨ **可观测最小集**：Actuator + Micrometer（Prometheus）+ OpenTelemetry Java agent；JSON 结构化日志输出到 stdout；不引入 Boot Admin。
⑩ **部署规范（R-011）**：compose 仅用于开发和本期运行；版本全部固定；引用 k8s-ready 清单
  （`assets/多租户与云原生演进.md` §3.3）；Helm chart 目录结构约定；定时任务使用 ShedLock。
排除：ES、k8s 集群运行、服务网格、原生推送、租户开通控制面（明确写"延后"）。
