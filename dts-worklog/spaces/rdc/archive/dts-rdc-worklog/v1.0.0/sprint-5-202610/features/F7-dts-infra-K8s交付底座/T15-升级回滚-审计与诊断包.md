# T15: 升级/回滚/升级前备份、审计事件与诊断包

**原编号**: 新增（2026-09-29，F7 dts-infra K8s 交付底座）

**优先级**: P0 · **状态**: DRAFT · **工作包**: P2 · **估算**: 20–31 人天 · **依赖**: T10、T14、T21（Kafka 就绪）

## 目标
实现 `upgrade`/`rollback`（含 forward-only 组件的强制备份与恢复提示）、`pkg/audit`（CloudEvents + journal 补发）与 `support-bundle`（脱敏）。

## 技术设计 (Contract-first)
- **设计依据**: [`design/00`](design/00-dts-infra-K8s交付底座设计.md) §3.5 回滚、§3.7、§4.3、§4.4（本 Task 不重复设计内容）。
- **输入**: 账本契约 `dts.audit.v1`（Sprint README 主竖线审计层）；T22 备份接口
- **输出契约**: 审计事件 `dts.infra.*`（字段见设计 §3.7）；journal `/var/lib/dts/audit/journal.ndjson`；`dtsctl upgrade|rollback|support-bundle`；脱敏规则表
- **错误路径**: Kafka 不可用 → 写 journal 不阻塞操作；补发按事件 id 幂等；诊断包中检测到疑似密钥 → 终止打包

## 影响范围
dts-infra `pkg/audit`、`pkg/supportbundle`、`cmd/dtsctl`
