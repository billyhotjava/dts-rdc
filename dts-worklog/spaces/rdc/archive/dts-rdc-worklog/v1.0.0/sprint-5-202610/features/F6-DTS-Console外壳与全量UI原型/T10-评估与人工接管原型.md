# T10: 评估与人工接管原型

**原编号**: 新增（2026-09-27，ADR-013 交付方法：模板化 UI 原型先行）

**优先级**: P1 · **状态**: DRAFT · **依赖**: T02–T04

## 目标
`/evaluation` 展示问数评测结果（golden set 通过/拒绝/失败、证据覆盖、时延与成本），并显示 AI 开关与降级状态、人工路径入口。

## 技术设计 / UI 规格
- 评测视图：按领域/路由的通过率、未通过样本列表（保留原样本）、趋势。
- 接管视图：AI 能力状态（启用/降级/关闭）；关闭后的人工路径（PRS 原页面、stack BI）入口；关闭操作仅平台管理员可用，二次确认并写审计。
- 指标定义取自 F0/T18、产品能力规划 §5。
- 契约 `evaluation.openapi.yaml`。
