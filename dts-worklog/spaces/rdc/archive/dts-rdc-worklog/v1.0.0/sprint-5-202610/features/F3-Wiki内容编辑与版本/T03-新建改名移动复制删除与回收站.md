## 技术设计
- git 绑定页的路径规则：`git_path = 挂载根 + 父路径 + 文件名`；文件名由标题生成（保留中文，替换 `/\:*?"<>|` 为 `-`，与 sprint-workflow 的 `T{NN}-{中文名}.md` 兼容），改名时重算。
- 操作 → 版本/同步语义：
  | 操作 | PG | git（F4 写回） |
  |------|----|----------------|
  | 新建 | page + version 1 | 新文件 |
  | 改名/移动 | 更新 title/parent/git_path | `git mv`（保留历史） |
  | 复制 | 新 page，version 1 = 源最新内容 | 新文件 |
  | 删除 | `deleted_at`（回收站 30 天） | `git rm` |
  | 恢复 | 清 `deleted_at` | 重新写回文件 |
- 移动 FOLDER 页：子树整体移动，对应目录 `git mv`。
- 跨"git 挂载根"移动（如从 worklog 移到 wiki 原生区域）：kind 由 GIT → NATIVE，git 侧 `git rm`，并二次确认。
