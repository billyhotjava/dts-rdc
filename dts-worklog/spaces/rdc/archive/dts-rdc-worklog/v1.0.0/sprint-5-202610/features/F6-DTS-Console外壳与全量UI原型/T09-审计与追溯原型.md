# T09: 审计与追溯原型

**原编号**: 新增（2026-09-27，ADR-013 交付方法：模板化 UI 原型先行）

**优先级**: P1 · **状态**: DRAFT · **依赖**: T02–T04

## 目标
`/audit` 按时间、主体（人/Agent）、租户、事件类型、traceId 查询审计事件，并能看到一次问答从提问到查询到回答的完整链路。

## 技术设计 / UI 规格
- 列表：时间、主体、类型（asked/query/answered/denied/pack.activated…）、租户、结果、traceId。
- 链路视图：按 traceId 展示事件时间线（与 `dts.audit.v1` CloudEvents 字段对应，见 BL-S/T14）。
- 只读；导出 CSV 需审计员角色。
- 契约 `audit.openapi.yaml`。
