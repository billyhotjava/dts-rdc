# T16: ADR-010 版本基线评估（JDK 25 / Boot 4 spike）

**原编号**: Sprint-5 F2/T05（2026-09-26 按月度 Sprint 整合重编号）

**优先级**: P1
**状态**: DRAFT
**依赖**: T01

## 目标
用限时 spike（≤ 2 人日）评估 stack 与头脑从 Java 21 / Boot 3.4.5 升到 prs R-012 基线（JDK 25 / Boot 4.1.x）的成本，
确定平台跟进路线与过渡期互操作契约；继承 PRS R-012 已锁定版本，不因旧原型版本较低而回退，本 sprint **不执行应用版本升级**。

## 技术设计
- **输入**：账本#26；prs `sprint-1-202609/assets/版本基线.md`。
- **Spike 步骤**：
  1. 在 scratch worktree 中，把 copilot（体量较小）的 parent 改成 Boot 4.1.x、`java.version=25`，执行 `mvn -B -q -DskipTests compile`，统计编译错误的类别（Jakarta、Spring Security 7、Jackson 3、Hibernate 7、Liquibase 5 等）；
  2. 同样对 stack 的 `dts-common` 和 `dts-platform` 做编译试探（只看错误数量与类别，不修复）；
  3. 前端：React 18 → 19（stack platform-webapp）的依赖冲突清单（`pnpm why react`，检查 antd、react-flow 等是否兼容）。
- **决策产出**：`docs/adr/ADR-010-version-baseline.md`，其中包括：错误类别统计、估算人日、推荐路径（例如"头脑 Q1 升级，stack 跟随 stack 自己的发布节奏"）、以及在版本分裂期间的**互操作约定**（只通过 HTTP/JSON + 身份头交互，不共享二进制 jar，prs-common 不被平台依赖）。
