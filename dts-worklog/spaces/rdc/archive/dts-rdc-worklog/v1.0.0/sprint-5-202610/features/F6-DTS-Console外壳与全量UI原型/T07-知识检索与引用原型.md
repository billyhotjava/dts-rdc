# T07: 知识检索与引用原型

**原编号**: 新增（2026-09-27，ADR-013 交付方法：模板化 UI 原型先行）

**优先级**: P1 · **状态**: DRAFT · **依赖**: T02–T04

## 目标
`/knowledge` 检索有权限的 Wiki 页面，展示摘要、空间、版本；点击在 Wiki 打开对应版本；工作台答案中的引用可跳转到此。

## 技术设计 / UI 规格
- 数据来自 Wiki 的 `/api/wiki/query`、检索接口与 `/markdown`（F3/T15）；BFF 只透传用户身份；原型阶段用契约 mock。
- 无权限空间的内容不出现在任何位置（标题、摘要、计数）。
- 契约 `knowledge.openapi.yaml`。
