# T03: 总部制品中心与构建/验证环境

**原编号**: 新增（2026-09-29，F7 dts-infra K8s 交付底座）

**优先级**: P0 · **状态**: READY · **工作包**: P0 · **估算**: 8–12 人天 · **依赖**: T01

## 目标
总部 Harbor、自托管 runner（x86 + 鲲鹏 arm64）、出站全丢弃的断网验收 VM、按需 ACK 测试集群全部可用，后续 Task 直接消费。

## 技术设计 (Contract-first)
- **设计依据**: [`design/00`](design/00-dts-infra-K8s交付底座设计.md) §4.1、§6.2、§6.3、§10 O8（本 Task 不重复设计内容）。
- **输入**: 现有 x86 服务器/VM（用户确认）；阿里云账号；GitHub 仓库（ssh 可达，https 不通，账本 W7）
- **输出契约**: Harbor（项目：`dts-images`、`dts-charts`、`dts-bundles`；cosign 签名策略；Trivy 扫描）；runner 标签 `dts-x86`、`dts-arm64`；断网 VM 模板（iptables 默认丢弃 egress，记录规则）；ACK 集群创建/销毁脚本与费用控制说明；环境清单 `assets/infra-env.md`（不含密码）；O8 采购/租用建议
- **错误路径**: Harbor 不可用时构建失败而非回退公共仓库；ACK 用完即销毁

## 影响范围
Harbor/runner 主机、`assets/infra-env.md`

## 验证（RED→GREEN）
- [ ] 从 runner 推送多架构测试镜像并完成签名与扫描
- [ ] 断网 VM 内 `curl https://github.com` 失败且规则可复查
- [ ] ACK 集群可用脚本创建与销毁

## Definition of Done
- [ ] 架构：输出契约有测试或可复查证据
- [ ] 切片：在断网 VM 或 ACK 的运行实例上验证（适用时），证据入 `../../it/infra/`
- [ ] 无占位证据
