# T03: 设计令牌与交互模式库

**原编号**: 新增（2026-09-27，ADR-013 交付方法：模板化 UI 原型先行）

**优先级**: P0 · **状态**: READY · **依赖**: T01

## 目标
一套 DTS 自有的视觉与交互模式，所有原型页只用这些模式，避免默认模板观感。

## 技术设计 / UI 规格
- 设计令牌：antd 6 `ConfigProvider` theme（色彩语义：成功/告警/拒绝/证据等级、数据新鲜度）、字体（中文正文 + 等宽数字）、间距与圆角层级；亮/暗两套。
- 页面模式：列表页（筛选栏 + 表格 + 批量操作）、详情页（摘要头 + 分区 + 右侧元数据）、向导/表单、抽屉详情、确认弹窗（危险操作二次确认）。
- 四态组件：`Empty` / `Loading`（骨架屏）/ `ErrorState`（错误码 + traceId + 重试）/ 成功反馈；所有原型页必须使用。
- 领域组件：证据等级徽标、口径版本标签、新鲜度指示、来源引用卡片、审计号链接、租户标识。
- 参考 shadcn-admin 的信息密度与排版节奏，遵守 `~/.claude/rules/web/design-quality.md` 的反模板要求。

## 验证（RED→GREEN）

- [ ] 可访问性：键盘可达、焦点可见、对比度达 WCAG AA
