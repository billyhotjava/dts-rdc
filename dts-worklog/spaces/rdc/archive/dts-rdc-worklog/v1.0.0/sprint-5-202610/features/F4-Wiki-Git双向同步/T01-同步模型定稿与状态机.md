**优先级**: P0 · **状态**: DRAFT · **依赖**: F2/T06

## 技术设计
- 页面同步状态：`SYNCED` →（网页编辑）`PENDING_PUSH` →（推送成功）`SYNCED`；入站发现双方都改 → `CONFLICT` →（合并）`PENDING_PUSH`。
- 文件识别：以 `git_path` 为主键；入站遇到 rename（`git diff -M`）→ 更新 `git_path` 而非删建，保留页面 id 与历史。
- 不纳入同步的文件：非 md/图片/附件扩展名、`.git*`、超过 20 MB 的文件（记日志）。
- 以文件为同步单位；同一次 push 中多文件变更逐文件处理，互不阻塞。
