# Worklog

Development records organized by the sprint-workflow skill:

```
v{x.y.z}/
├── sprint-queue.md               # sprint queue and cadence rules
├── sprint-{N}-{YYYYMM}/          # one sprint per calendar month
│   ├── README.md                 # goals, ADRs, feature list
│   ├── features/F{N}-{name}/     # feature README + T{NN}-{name}.md tasks
│   ├── assets/                   # reviews, spikes, handoffs
│   └── it/                       # acceptance evidence
└── backlog/                      # refined work beyond monthly capacity (BL-*)
```
